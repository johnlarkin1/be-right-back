A collapsible block that shows the model's reasoning before an answer.

Props: `thinking` (the text) and `defaultExpanded`.

- It is collapsed by default. The user opens it.
- Retro shows `[-] THINKING` in a violet outlined box. Modern shows a chevron, a brain icon and "Thinking".
- Violet marks reasoning in both modes. Do not use violet for answers.

Live React component. Source: `apps/desktop/src/components/casper/ThinkingBlock.tsx`.
