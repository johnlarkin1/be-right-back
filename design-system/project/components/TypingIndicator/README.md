Shows that the persona is writing a reply.

It takes no props. Put it at the end of the message list while a reply streams.

- Retro shows the `[DIGITAL-YOU]` label and three glowing dots in a persona bubble.
- Modern shows three gray dots in a rounded bubble.
- Remove it when the first token arrives. Then use `MessageBubble` with `isStreaming`.

Live React component. Source: `apps/desktop/src/components/chat/TypingIndicator.tsx`.
