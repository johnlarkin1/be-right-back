The article style of the marketing website. The "How it's built" pages use it.

This card is a specimen, not a component in the bundle. It restates the `.prose-brb` rules from the website with the `web-*` tokens. It looks the same in every theme.

- Body: Inter 17px, line height 1.7, in `web-crt-body` on `web-crt-bg`.
- Headings: Inter, weight 600 (700 for h1), in `web-crt-accent-soft`.
- Inline code: JetBrains Mono in `web-crt-text` on a faint green tint.
- Code blocks: `web-surface` fill, `web-border-subtle` border, 8px corners.
- Quotes: a 3px `web-crt-accent` rule on the left, italic, in `web-text-secondary`.

Static specimen. Source: `apps/website/src/app/globals.css`.
