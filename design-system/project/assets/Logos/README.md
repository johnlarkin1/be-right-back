# Logos

- `ghost.svg`: the pixel ghost mark. Its ink is `#00ff41` (`primitive-crt-green`) and its eyes are `#0a0e0a` (`primitive-crt-bg`). Use it on `color-surface` in retro. It is also the browser tab icon.
- `app-icon.png`: the macOS app icon, 256 by 256 pixels. A smooth green ghost on a black rounded square. Use it only where the operating system shows the app, or next to a download link.

Do not recolor, redraw or stretch either file.
